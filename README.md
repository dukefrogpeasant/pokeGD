# pokeGD
A ROM-Hack for Pokémon FR 1.0.

# Instructions
As a fair warning, if you pick anything from the Old Versions file, you're much, much more likely to encounter bugs and outdated mapping. The old versions exist so you can take a look at how this game develops overtime, but I strongly advise you to pick up the newest version(the newest version not in the old versions folder.).

This UPS patch needs to be applied to a vanilla FireRed 1.0 ROM.

This patch CANNOT be played as-is, and needs to be patched on what is mentioned above.

You can use older saves for this game even if you update it later down the line.
You should save in Pokémon Centers if you do upgrade versions, as these are safe locations that are unlikely to ever change.

I myself use https://www.marcrobledo.com/RomPatcher.js though anything else that supports UPS patching should probably work, too.
